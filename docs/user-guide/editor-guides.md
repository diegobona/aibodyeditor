# Editing photos with AI Body Editor

AI Body Editor uses the same editor on its homepage and three topic guides. The homepage uploader is directly below the short title at the top. A concept comparison is beside it on desktop and below it on mobile. Tools opens advice about body reshaping, slimming and clothed bust proportions.

Choose one JPG, PNG or WebP image up to 10 MB. Use a clear, clothed adult portrait that you have permission to edit. Selecting the file creates a local preview; it is sent for processing only when you submit an edit.

Choose a mode:

- **Slim** asks for a narrower waist and upper-arm outline.
- **Muscle** asks for athletic shoulder and arm definition under original clothing.
- **Proportions** asks for overall shoulder, waist and leg balance.
- **Breast** asks for a fuller bust silhouette under existing clothes, retaining neckline and coverage.

Choose Subtle, Balanced or Noticeable intensity. These express intended strength, not an exact measurement. Results vary with the photo, clothing and requested change.

Sign in and select **Edit my photo** to generate a result. Your selected original is retained while you sign in. Each account gets 15 trial credits once, enough for one edit; subsequent edits also use 15 credits. If an edit fails, the app returns its consumed credits. Generating another result uses credits, including after changing mode or intensity.

While processing, wait for the result instead of submitting again. If the connection is interrupted, check the edit status before starting another edit. Reloading the same browser tab while signed in can recover the pending or completed result without generating another image. After a reload, the result remains downloadable, but the local original is no longer available for side-by-side comparison.

When the result appears, compare it with the original by dragging the comparison handle or using arrow keys. Inspect the face, hands, clothing seams and nearby background lines. The instructions ask to retain these details, but preservation is not guaranteed. Use **Download photo** to save the result or **Edit another photo** to choose a new original.

If the saved result's preview cannot load, select **Reload image**. This retrieves the existing result without generating another image or using credits. The preview keeps its space while loading; comparison becomes available once the image has loaded.

Submitting sends the original to Rabbit API for processing. The app does not persistently store the uploaded original on its server. Generated results are stored privately for your account and accessed through signed-in, owner-checked links. Provider processing and retention are separate from this app's result storage.

The homepage's Slim, Muscle and Proportions examples are original AI-generated concepts. They illustrate directions and are not results from this editor. **Preview Slim**, **Preview Muscle** or **Preview Proportions**, including thumbnails under **Try a sample photo**, loads the example's original half into the same top uploader. Then choose any of the four modes and an intensity. Selecting a sample alone generates nothing; submitting it uses the same sign-in and credit flow as a local photo. A device photo replaces the sample, and **Clear sample** removes it.

Each guide retains its own photo advice and FAQs while using the same editor. On desktop, open Tools to choose a guide. On mobile, open the main menu and select the guide there.
