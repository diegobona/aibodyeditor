# Editing photos with AI Body Editor

AI Body Editor uses the same editor on its homepage and three topic guides. The homepage uploader is directly below the short title at the top. A concept comparison is beside it on desktop and below it on mobile. Tools opens advice about body reshaping, slimming and clothed bust proportions.

Choose one JPG, PNG or WebP image up to 10 MB. Use a clear, clothed adult portrait that you have permission to edit. Selecting the file creates a local preview; it is sent for processing only when you submit an edit.

Choose a mode:

- **Slim** asks for a slimmer waist, abdomen, upper arms and visible thighs.
- **Muscle** asks for stronger shoulders, arms and chest, with muscle volume under original clothing and abdominal definition where already visible.
- **Proportions** asks for longer-looking legs relative to the torso and a more defined waist within the original frame.
- **Breast** asks for a fuller bust silhouette under existing clothes, retaining neckline and coverage.

Set the **Intensity** slider anywhere from 1 to 100. It starts at 70 for a clearly visible change. Lower values request subtle adjustments and higher values request a dramatic transformation. Arrow keys adjust by one; Home and End select the endpoints. The number describes editing strength, not a body-size percentage or an exact measurement. Results vary with the photo, clothing and requested change. Moving the slider does not generate an image or consume credits; select **Edit Photo** to apply it.

For a more specific request, open **Extra instructions (optional)** and describe what to change, for example: “Only slim my waist; keep my arms and legs unchanged.” Leave it blank to use the selected mode normally. You can enter up to 500 characters. Instructions can limit or replace the preset's body-change target; face, clothing coverage, scene and framing should stay the same. Results still require review. Typing does not generate an edit, and the local outline continues to show the selected mode and intensity. The text stays while changing modes or signing in; selecting another photo or sample clears it.

After selecting a device photo, wait for the local outline analysis. A gray outline marks the original silhouette and a purple outline shows the selected target. Move Intensity or switch modes to update that target immediately, before generating. You can hide the overlay to see the original clearly or adjust its alignment when needed. These controls are free and do not send your photo for generation.

The outline is a target guide, not a guaranteed prediction of the generated result. Clothing and occlusion affect recognition, and a visible silhouette does not reveal hidden anatomy. If the outline cannot be detected, you can replace the photo or continue with normal generation. Example gallery photos retain their existing sample-preview flow.

Breast preview limits contour changes to plausible visible torso edges and excludes detected arm paths. When the chest edge is covered, cannot be localized reliably, or has no measurable change in the selected region, a purple dashed ellipse marks the approximate chest area alongside the original outline. The ellipse grows or shrinks continuously as you move Intensity, indicating the requested strength rather than predicting an exact edited silhouette. Select **Align** to move it with a drag or arrow keys, and **Reset alignment** to restore its position. Changing intensity preserves your aligned position. These controls adjust the local preview only; they do not change generation inputs. A covered boundary cannot be measured precisely from the silhouette, and the preview does not invent it. You can still generate an edit.

Select **Edit Photo** to generate your first guest result free without signing in. The allowance is one successful edit per browser; keep cookies to retain access and quota. If generation fails, the free opportunity is restored, subject to retry limits. Once used, sign in to continue with account credits. Signing in grants no additional free edit, and your selected original stays available while signing in. Signed-in edits cost 15 credits each; a failed edit returns consumed credits. Changing mode or intensity and generating again is another edit.

While processing, wait for the result instead of submitting again. If the connection is interrupted, check the edit status before starting another edit. Reloading the same browser tab can recover the pending or completed result using its guest cookie or account session without generating another image. After a reload, the result remains downloadable, but the local original is no longer available for side-by-side comparison.

When the result appears, compare it with the original by dragging the comparison handle or using arrow keys. Inspect the face, hands, clothing seams and nearby background lines. The instructions ask to retain these details, but preservation is not guaranteed. Use **Download photo** to save the result or **Edit another photo** to choose a new original.

If the saved result's preview cannot load, select **Reload image**. This retrieves the existing result without generating another image or using credits. The preview keeps its space while loading; comparison becomes available once the image has loaded.

Submitting sends the original to Rabbit API for processing. The app does not persistently store the uploaded original on its server. Generated results are stored privately and accessed through owner-checked links using your browser guest cookie or account session. Provider processing and retention are separate from this app's result storage.

The homepage's Slim, Muscle and Proportions examples are original AI-generated concepts. They illustrate directions and are not results from this editor. **Preview Slim**, **Preview Muscle** or **Preview Proportions**, including thumbnails under **Try a sample photo**, loads the example's original half into the same top uploader. Then choose any of the four modes and an intensity. Selecting a sample alone generates nothing; submitting it uses the same guest allowance or account credits as a local photo. A device photo replaces the sample.

Each guide retains its own photo advice and FAQs while using the same editor. On desktop, open Tools to choose a guide. On mobile, open the main menu and select the guide there.
