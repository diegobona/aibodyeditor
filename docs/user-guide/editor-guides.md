## Free guest edit and welcome credits

You can generate one successful guest edit per browser without signing in. Afterward, sign in or create an account in the editor dialog. Your current photo, result and settings stay in place. Your account receives 10 welcome credits once, enough for one generation. These are ordinary credits: use them for a fresh edit or for Continue editing. Signing in, registering or loading a continued result does not automatically generate a photo or spend credits.

The editor displays the current balance and the 10-credit generation cost. When the balance is insufficient, Get credits opens the credit-pack dialog. Purchases are not yet available, and the dialog states this explicitly; returning to the editor retains your images and settings. Opening or downloading an existing result remains available. Repeated login or refresh does not issue another welcome grant. Legacy account-trial grants count as already received. Failed credit-based generations return their original debit.

## Continue editing

After generating a result, choose **Continue editing** beside the result controls to use that image as the next original. You must be signed in with at least 10 credits in your account. This uses the current account balance, including granted credits; it does not require a purchase record. The editor keeps the current mode, intensity and instructions for you to adjust, clears the result panel and returns to the original view on mobile. This action loads the existing file without resizing it; it does not start a generation or spend credits.

Select **Edit Photo** when the next settings are ready. That creates a separate request costing 10 credits, with a fresh balance check. Guests can preview and download their free result, but must sign in with enough credits to continue editing. A signed-in user's previous result remains in My works until deleted or expired. If the balance is insufficient or the result cannot be loaded for continuation, the existing original and result remain available and the action can be retried. This works on both the homepage and the topic-guide editors.

## Output specifications

After a generated result finishes loading, the editor shows its actual pixel dimensions, file format and file size below the result. My works displays the same information on each loaded image card and in the large-image view. These values describe the generated file, not the size of its onscreen preview. Download keeps the original generated bytes; the service does not add an unverified HD/4K label or upscale the file during download.
