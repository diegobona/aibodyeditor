# Editing photos with AI Body Editor

AI Body Editor uses the same editor on its homepage and three topic guides. The homepage uploader is directly below the short title at the top, with ten real editing examples to try. The selected example's saved comparison is beside it on desktop and below it on mobile. Tools opens advice about body reshaping, slimming and clothed bust proportions.

Choose one JPG, PNG or WebP image up to 10 MB. Use a clear, clothed adult portrait that you have permission to edit. Selecting the file creates a local preview; it is sent for processing only when you submit an edit.

Choose a mode:

- **Slim** asks for a slimmer waist, abdomen, upper arms and visible thighs.
- **Muscle** asks for stronger shoulders, arms and chest, with muscle volume under original clothing and abdominal definition where already visible.
- **Proportions** asks for longer-looking legs relative to the torso and a more defined waist within the original frame.
- **Breast** asks for a fuller bust silhouette under existing clothes, retaining neckline and coverage.

Set the **Intensity** slider anywhere from 1 to 100. It starts at 70 for a clearly visible change. Lower values request subtle adjustments and higher values request a dramatic transformation. Arrow keys adjust by one; Home and End select the endpoints. The number describes editing strength, not a body-size percentage or an exact measurement. Results vary with the photo, clothing and requested change. Moving the slider does not generate an image or consume credits; select **Edit Photo** to apply it.

For a more specific request, open **Extra instructions (optional)** and describe what to change, for example: “Only slim my waist; keep my arms and legs unchanged.” Leave it blank to use the selected mode normally. You can enter up to 500 characters. Instructions can limit or replace the preset's body-change target; face, clothing coverage, scene and framing should stay the same. Results still require review. Typing does not generate an edit, and the local outline continues to show the selected mode and intensity. The text stays while changing modes or signing in. On the homepage it also stays when choosing a device photo. Choosing an example replaces it with that case's submitted instructions, or clears it when the case has none; instructions open automatically when present.

After selecting a device photo, wait for the local outline analysis. A gray outline marks the original silhouette and a purple outline shows the selected target. Move Intensity or switch modes to update that target immediately, before generating. You can hide the overlay to see the original clearly or adjust its alignment when needed. These controls are free and do not send your photo for generation.

The outline is a target guide, not a guaranteed prediction of the generated result. Clothing and occlusion affect recognition, and a visible silhouette does not reveal hidden anatomy. If the outline cannot be detected, you can replace the photo or continue with normal generation. Example photos show their saved reference result.

Breast preview limits contour changes to plausible visible torso edges and excludes detected arm paths. Breast mode always shows a purple dashed ellipse marking the approximate chest area alongside the original outline, with a purple target contour when usable side-edge changes are available. The ellipse position is estimated from shoulder and hip landmarks; the model does not specifically segment the chest. Other modes do not show this ellipse. The ellipse grows or shrinks continuously as you move Intensity, indicating the requested strength rather than predicting an exact edited silhouette. Select **Align** to move it with a drag or arrow keys, and **Reset alignment** to restore its position. Changing intensity preserves your aligned position. These controls adjust the local preview only; they do not change generation inputs. A covered boundary cannot be measured precisely from the silhouette, and the preview does not invent it. You can still generate an edit.

Select **Edit Photo** to generate your first guest result free without signing in. The allowance is one successful edit per browser; keep cookies to retain access and quota. If generation fails, the free opportunity is restored, subject to retry limits. Once used, sign in to continue with account credits. Signing in grants no additional free edit, and your selected original stays available while signing in. Signed-in edits cost 15 credits each; a failed edit returns consumed credits. Changing mode or intensity and generating again is another edit.

While processing, wait for the result instead of submitting again. If the connection is interrupted, check the edit status before starting another edit. Reloading the same browser tab can recover the pending or completed result using its guest cookie or account session without generating another image. After a reload, the result remains downloadable, but the local original is no longer available for side-by-side comparison.

When the result appears, compare it with the original by dragging the comparison handle or using arrow keys. Inspect the face, hands, clothing seams and nearby background lines. The instructions ask to retain these details, but preservation is not guaranteed. Use **Download photo** to save the result or **Edit another photo** to choose a new original.

If the saved result's preview cannot load, select **Reload image**. This retrieves the existing result without generating another image or using credits. The preview keeps its space while loading; comparison becomes available once the image has loaded.

Submitting sends the original to Rabbit API for processing. The app does not persistently store the uploaded original on its server. Generated results are stored privately and accessed through owner-checked links using your browser guest cookie or account session. Provider processing and retention are separate from this app's result storage.

The homepage starts with an empty upload canvas, Slim at intensity 70 and blank extra instructions. The horizontal **Try an example** strip contains ten actual cases. Selecting a case loads its original photo, mode, exact intensity and submitted instructions, and displays the saved edited image beside the original. No dragging is required. **Only apply settings** defaults off and is disabled until a photo is loaded. Turn it on to keep the current photo and its result while applying a case's settings. Switching the toggle itself changes nothing; it affects the next case selection. Selecting a device photo preserves settings and clears the previous result.

On desktop, original, result and settings sit in one workbench. On mobile, use the **Original** and **Result** tabs with settings below. After generating, the result appears directly with **Download photo**. Changing settings keeps the existing result with a reminder to generate again. Uploading a new original clears the old result. Pending or uncertain edits lock changes until the request is resolved. Topic guides retain their compact editor and comparison handle.

**Choose what to edit** explains all four modes without another photo gallery. Its **Use** links select a mode and return to the uploader while preserving your selected photo. **Check your result before downloading** gives face, clothing and background checks without repeating the comparison portraits.

The ten examples use ten different fictional adult people, including a Black man, a Black woman, an East Asian woman and a white man, with dresses, skirts, shorts and trousers. Scroll the strip or use its arrows to see all ten. Saved results correspond to the loaded sample photo and remain unchanged while editing controls change. Applying another recipe with **Only apply settings** enabled never substitutes a different person's result. Browsing examples and toggling this switch never generate an edit; only **Edit Photo** submits using the usual guest allowance or account credits. Source portraits are AI-created; editing results come from the same editing pipeline as the tool and are only resized and compressed for display.

Each guide retains its own photo advice and FAQs while using the same editor. On desktop, open Tools to choose a guide. On mobile, open the main menu and select the guide there.


The **Actual results from this editor** gallery below the workbench displays all ten cases in four desktop columns, two tablet columns and one mobile column. Each card has an original/actual comparison slider, mode, intensity, any submitted instructions and **Try**. Drag the handle or use keyboard arrows, Home and End to inspect the difference. **Try** returns to the editor and applies the case using the **Only apply settings** option beside that card's Try button. With that switch off, the case photo and recipe load together; with it on, the current photo and corresponding result stay in place. Try never generates or consumes the guest allowance. Pending/uncertain edits disable Try. The workbench itself continues to display its result directly. The two Breast examples are labelled **Breast · Fuller** and **Breast · Subtle** in the top strip.


**Only apply settings** is independent for each gallery card and defaults off. Changing one card does not change other cards or the top-strip option. The top-strip option affects top thumbnail selections only. Each card's Try uses its own option: off loads the case photo and recipe, on keeps the current photo/result and applies the recipe only. All options are disabled without a loaded photo or during pending/uncertain edits. Toggling alone changes no photo or result.

**Edit Photo** submits the mode, intensity and instructions currently shown in the editor. Changing mode clears instructions inherited automatically from a sample so its old body-change request cannot override the new mode. Instructions you write yourself stay in place. A saved example is a reference for its original recipe until you generate; it does not update automatically with the controls.

Starting generation clears the saved example from the result pane. Pending edits show progress and the submitted mode/strength. If the connection is interrupted, the pane says **No new result yet** and offers the existing **Check edit status** action instead of showing the old sample as the result. Recovery reuses the original request and settings. A successful result shows the returned image and its mode/strength; inspect it before downloading.
